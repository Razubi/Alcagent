# Spec 009 — Guard autonomy and reporting

Status: pending

## Requirements
Guards are independent subagents with duties, fatigue, stress, opinions, and imperfect reporting.

## Acceptance criteria
- [ ] Guards observe assigned areas, interact with prisoners, report incidents, and request assistance.
- [ ] Guards can make mistakes, become exhausted/stressed, form opinions, and occasionally violate policy.
- [ ] Warden receives reports rather than omniscient event access.
- [ ] Guard duty changes alter prisoner behavior and incident likelihood.
- [ ] Add deterministic tests for reporting/fatigue consequences; full workspace passes.
